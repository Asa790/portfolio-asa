# Khalisa Kasih Redwina — Portfolio

Personal portfolio website for **Khalisa Kasih Redwina**, Computer Science (Software Engineering) student at BINUS University Bekasi. Designed with a luxury dark burgundy editorial aesthetic, glassmorphism, dynamic ambient glow, and interactive showcases.

---

## 🌟 Highlights

- **Luxury Burgundy Editorial Theme**: Glassmorphism cards, glowing ambient aurora background, and serif typography.
- **Projects Showcase**: Curated machine learning, full-stack, and software engineering projects with live previews and repository links.
- **Experience & Certificates**: Leadership milestones, organizational impact (HIMTI), and documentation gallery with fullscreen lightbox preview.
- **Skills Matrix**: Separated technical hard skills (with brand icons) and core interpersonal/language competencies.
- **Direct Contact Form**: Connected with Web3Forms to deliver inquiries straight to email.
- **Mobile Responsive**: Fully responsive layout with mobile drawer navigation and direct CV download.

---

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Vanilla CSS, Glassmorphism & Custom Keyframe Shaders
- **Icons**: Lucide React & Devicon CDN
- **Form Delivery**: Web3Forms API
- **Deployment**: Vercel

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
